# Changelog

All notable changes to `python-wealthfolio` are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.1.0]

Initial release of the Python REST client and CLI for Wealthfolio.

- Typed responses for accounts, activities, holdings, performance, net worth,
  income, goals, contribution limits, health, portfolios, taxonomies,
  categorization, valuations, allocations, imports, snapshots, and assets.
- Password-based session authentication with explicit connection settings.
- CLI queries, validation, and write previews with explicit confirmation.
- MIT license, offline tests, and GitHub Actions CI.
